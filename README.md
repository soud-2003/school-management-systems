# School Management System

A comprehensive school management system built with Django (backend) and React (frontend).

## Features

- Student management
- Teacher management  
- Parent portal
- Result management
- Account information management

## Tech Stack

- **Backend**: Django, Django REST Framework
- **Frontend**: React, Vite

## Setup

### Backend
```
bash
cd backend/school_management
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend
```
bash
cd frontend/frontend
npm install
npm run dev
```
